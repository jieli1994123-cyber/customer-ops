Everything in this folder is **invented** (product, founder, leads, replies) to show the shape of a real run. Real runs write to `profile/`, `leads/`, `tracker.md` in your own copy — never here.

**The fictional setup:** Maya builds **CartBack**, a WhatsApp abandoned-cart recovery tool for Shopify stores, $29/mo. She ran `/setup` from inside the CartBack repo (Path A) — the profile below is what the repo scan drafted and she confirmed.

Files in this demo:

- `profile/product.md` + `profile/icp.md` — the confirmed `/setup` output
- `shortlist.md` — the `/score` output for one `/discover` batch (5 shown of 23 scored)
- `leads/fernwood-candle-co/research.md` — one lead's sourced research (`/score` + `/contacts`)
- `leads/fernwood-candle-co/draft.md` — the drafter–reviewer paper trail (`/draft`)
- `outcome.md` — what `/outcome` did with two replies
